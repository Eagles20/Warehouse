# UI screens

Each screen of the Warehouse system is shown as a simple picture (wireframe) with sample data. Each picture is linked to its feature, and each feature file links back to its pictures in the **Screen Requirements** section.

- **Office computer** screens are 1280 px wide, **tablet** 860 px, **handheld** and **phone** 390 px.
- The left menu on office and tablet screens is the same for all roles. A user sees only the features of his or her role (ADR-006).
- The pictures are drafts. They show what each screen must contain, not the final colors or fonts.
